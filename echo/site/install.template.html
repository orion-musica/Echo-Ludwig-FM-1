Install Echo Ludwig

Put the game on your M-VAVE FM-1 from the browser, over a USB cable. No drivers, no apps. About five minutes.

ExperimentalEcho Ludwig is new and has been tested on very few devices. Back up first, and keep the FM-1 powered and connected until the installer says it is done. The original firmware is built into the installer, so you can always go back.

What you need

An FM-1

Any M-VAVE FM-1, on its original V15 firmware or an FM1 Open build. Charged, or on USB power.

A USB data cable

One that carries data, not just power. Plug it straight into the computer, not into a hub.

Chrome or Edge

On Windows, macOS or Linux. Allow MIDI and SysEx when the browser asks.

Steps

  1. Back up

    Export the projects, voices and samples you want to keep in the M-VAVE workbench. Echo Ludwig keeps its progress in the storage place of project slot 15. Close DAWs and other MIDI apps.

  2. Connect

    Switch the FM-1 on, plug in the cable, choose Start the installer, then Connect device. Allow MIDI and SysEx.

  3. First time from V15

    The installer finds FM-1_015. Choose Enable force flash and reconnect. Nothing is written yet. Coming from FM1 Open? Skip this step.

  4. Install

    Tick the backup confirmation, choose Force flash or Install, and accept the warning. Do not unplug while it writes.

  5. Play

    Wait for the sample check to finish. The FM-1 restarts and Ludwig says “Welcome to Echo Ludwig”.

The installer page itself comes from FM1 Open and looks different from this website. If it is hard to use with your screen reader, ask a sighted friend for these few steps; after that, the game speaks for itself.

Back to the original firmware

Changed your mind? Open the installer and choose Restore original V15. It installs the original firmware and restores all 128 factory voices.

ProgressThe original firmware does not keep Echo Ludwig's stars and settings. To come back to Echo Ludwig later, use force flash again.

Help

The browser does not find the FM-1

Close other MIDI apps and installer tabs, switch the FM-1 off and on, reconnect the cable and choose Connect again. Connection details in the installer show which MIDI ports the browser found.

The start button does not work

The ready check above says why. Wrong browser: use Chrome or Edge on a computer; Safari, Firefox and phones cannot talk to MIDI devices. Opened as a file: run OPEN-SITE.bat so the page runs on localhost.

The update stopped halfway

Keep the cable in, switch the FM-1 off and on, reconnect and run the installer again with force flash.

It says NOT BUILT

The firmware has to be compiled once. On Windows run INSTALL-ECHO.bat in the project folder. It builds Echo Ludwig and opens this page on http://localhost:8766.

Will I lose my projects?

An update with the same storage layout keeps valid project slots and the sample bank; Echo Ludwig uses slot 15 for its progress. Switching from V15 does not keep them. Back up either way.

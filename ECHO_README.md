# Echo Ludwig — player notes

Echo Ludwig is an echo game for blind players on the M-VAVE FM-1. Ludwig speaks every menu;
the screen stays black with one small white message for sighted helpers.

## How to play

1. Ludwig says **listen** and plays a short melody.
2. A two-note signal means **your turn**: play the melody back on the keys.
3. A wrong note? Ludwig says **higher** or **lower**. On Normal you lose a life and hear the melody again.
4. Every round the melody grows by one or two notes. Play it all to unlock the record and hear the **drop**.

Stars: 3 = no mistakes and no hints, 2 = up to 2 mistakes, 1 = finished.
Three records in a crate open the next crate. Ranks: Beginner, Apprentice, Musician, Soloist, Maestro.

## Controls

| FM-1 | In menus | In the game |
| --- | --- | --- |
| knob 1, OCT− / OCT+ | previous / next | — |
| knob 2 | change a setting | — |
| PLAY | select | listen again |
| HOME | back (hold: main menu) | pause |
| REC | repeat what Ludwig said | same |
| EDIT | help for this place | game help |
| ARP | rank and stars | score, round, lives |
| SEQ | — | hint: plays the next note |
| SCL / ENV / GLO | speech speed / how much Ludwig talks / voice | same |
| FX | listening beat on/off | same |
| SAVE | save progress | same |

Middle C is the 8th key from the left; the lowest key is F. **Key Explorer** (main menu) names every key and button.

Every press sends a light wave over the LEDs and flashes the screen white, at most 3 flashes a second.
Settings → Lights: off / wave / wave and flash.

## Storage

Progress (stars, best scores, settings) lives in the Flash place of **project slot 15**. Back up your projects first.
